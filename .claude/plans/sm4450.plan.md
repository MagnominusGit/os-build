## Decisions

- 40 of 46 ROCKNIX SM4450 kernel patches taken (kernel/patches/README.md "SM4450 port").
  Skipped as already carried: 0016, 0019 (our 0370 is its v2), 0041, 0045-0048. Skipped by
  policy: 0054 (battmgr sysfs rename, breaks every SM8550+ profile), 0034 (aw88166 volume
  inversion, would mute Thor's UCM 0).
- Scoped to SM4450 so the combined kernel keeps other SoCs unchanged: 0286 (A613 SPTPRAC), 0862
  (SoundWire EE0). 0826 written on top of our 0820/0825 (senary MI2S).
- Fleet-wide and owed a HW check elsewhere: 0831 aw88166 PLL (Thor Lite / Odin 3 speakers), 1091
  geni RX restart (an rsinput board's pad + BT), 1063 qmp-combo runtime-PM (posted upstream).
- UCM speaker = software volume (our aw88166 semantics); HP Volume remap as on Odin 3.
- WCN3950 BT: the SM6115 set (BTFM 00116) stays at the default `qca/` names; ROCKNIX's SM4450 set
  (00125) is in `qca/sm4450/`, named by the SM4450 DTS `firmware-name = "sm4450/cmnv13",
  "sm4450/cmbtfw13.tlv"`. Patch 1027 makes that NVM stem keep the s/t flavour (and no board-id
  suffix) the default name has. HW: dmesg shows which `qca/sm4450/cmnv13*.bin` loads.
- Wi-Fi: generic ath10k WCN3990 board-2/firmware-5 from linux-firmware (LINUX_FW.pin); WLAN fw is
  inside wpss.mbn, so no rmtfs/tqftpserv (ROCKNIX does not run them on SM4450 either).
- session.conf: TU_DEBUG=noconform for SM4450 (gen1_low, no hw multiview). Plane rotation as on
  SM8xxx: 1080-wide panels sit under SM4450's 1200-line rotator cap.
- GRUB rotation 90 (ROCKNIX GRUB_ROTATION="90"), bootargs `gpt` only.

## HW results (RG 55G1, 2026-10-26)

OK: boot, GRUB entries, splash upright (after 50a5acaf: no simple-framebuffer, msm is card0), panel
61 Hz, touch, OGUI orientation, gamepad, Wi-Fi (ath10k WLAN.HL.3.4.3 on WPSS), Bluetooth (one
power-on retry, then qca/sm4450/cmbtfw13.tlv + cmnv13s.bin: the chip is the "s" flavour, 1027
works), speakers, headphones.

Found and fixed: 0535 and mainline chipwealth both registered "panel-ch13726a-amoled"; mainline
links first, so 0535 (RP5 / Mini / Mini V2 / Thor bottom) would not register (5e342949, renamed).

LEDs (2026-10-27, HW-OK): the status light is three separate on/off lamps, red/green/AMBER
(tlmm 49 is amber; ROCKNIX's DTS calls it blue). 0763 rewritten: the 16 ring segments are multicolor
LED class devices rgb:l1-l8 / rgb:r1-r8, grouped ring-left/ring-right in the profile; powerd lights
the one on/off lamp nearest the colour (default blue -> green lamp, rings blue).

Rumble (2026-10-27, HW-OK): pm7250b vibrator (pm8xxx_vib_ffmemless) through the InputPlumber
composite; FF_RUMBLE on the virtual xbox-elite pad, strong-only 1 s and weak-only 0.5 s both felt.

Open (dmesg):
- aw88166 0-0034/0-0035 "start failure (-1)" on every start, yet the speakers play: the start
  check (0831's PLL/status path) reports failure. Get the reason with dyndbg on a fresh start.
- "[dpu error]INTF_1: boot scanout did not stop" (0370 times out on OpenABL's splash; harmless).
- "fb0: sys_imageblit: framebuffer is not in virtual address space" (msm fbcon text console).
- Noise: fsa4480 not found (absent part), spi_mcu no spi_device_id, one qcom-apm CMD timeout,
  wcd937x impedance ramp errors with nothing plugged, ath10k "chan info: invalid frequency 0".
